# ScreenSafe packs

The community pack catalog for [ScreenSafe](https://github.com/jeremydixon22/omarchy-screensafe), screensavers for Omarchy made of data, not code.

**Submissions are not open yet.** There are no community listings. The validation and review workflows described in [Community packs](https://github.com/jeremydixon22/omarchy-screensafe/blob/main/docs/COMMUNITY.md) have not been implemented in this repository. This README will announce when the catalog is ready to accept pack submissions.

ScreenSafe already includes built-in packs in its [plugin repository](https://github.com/jeremydixon22/omarchy-screensafe/tree/main/packs). To make your own, start with [Making a screensaver](https://github.com/jeremydixon22/omarchy-screensafe/blob/main/docs/MAKING.md).

When submissions open, `packs.toml` will list approved packs at exact commits in their makers' repositories. Listing a pack will not install it, and ScreenSafe never fetches or installs packs from this catalog.
